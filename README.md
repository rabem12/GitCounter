# GitHub Counter Widget for macOS

A beautiful, native macOS desktop widget that tracks the total download count and latest release metrics for any public GitHub repository.

## 🚀 How to Install and Use

This project is completely open-source and requires **no Apple Developer Account**, **no Team provisioning**, and **no terminal setup** to run locally on your Mac!

### 1. Download the App
1. Clone or download this repository to your Mac.
2. Double-click **`GithubCounter.xcodeproj`** to open it in Xcode.

### 2. Build and Run
1. In Xcode, hit **`Cmd + R`** (or click the Play button in the top left).
2. The app will compile and launch.
3. You can close the app window—the widget is now registered with your Mac!

### 3. Add to your Desktop
1. Right-click anywhere on your Mac's desktop and select **"Edit Widgets..."**.
2. Search for **"GithubCounter"** in the widget gallery.
3. Drag the widget onto your desktop.
4. Right-click the widget, select **"Edit GithubCounter"**, and enter your favorite `Owner/Repo` (for example: `apple/swift`).

## 🛠 Tech Stack
- **SwiftUI** & **WidgetKit**
- Native macOS **Ad-Hoc Signing** (Manual)
- Generated via **XcodeGen**
